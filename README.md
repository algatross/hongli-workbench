# 红利买点工作台

一个单文件的红利股买点看板。打开即用，行情实时抓，持仓/自选只存在你自己手机里。

> **线上地址：https://algatross.github.io/hongli-workbench/**（手机添加到主屏幕可当 App 用）

七个页面：

- **买点**：按目标股息率（3%~9%）倒算「跌到多少才值得买」，标出当前价已经触到哪一档。每张卡片带一条**布林轨道尺**，一眼看出便宜还是贵
- **自选**：日常关注的股票，**不限池内**。填代码或名称即可加入，自动拉价；池内标的会自动带出分红与税率。支持按股息率 / 涨跌幅排序、写备注
- **行业**：12 个一级行业、110 只标的，看各行业股息率中位数水位
- **矩阵**：全池按股息率 / 距下一档差距排出强弱；可切「布林 × 股息 交叉」看四象限
- **持仓**：算成本、算浮盈、算成本股息率 CDY；年税后分红与月均被动收入
- **推演**：改股价 / 股数，实时算加仓后的摊薄成本与 CDY 变化
- **数据**：数据源、最后一次成功刷新时间、版本号、导出导入

## 布林通道怎么看

采用 **20 日 ±2σ、前复权**，与通达信 / 同花顺默认口径一致（标准差用「总体」而不是「样本」，否则轨会偏宽，跟你看盘的软件对不上）。

| 位置（现价在上下轨之间） | 标签 | 含义 |
| --- | --- | --- |
| < 0% | 跌破下轨 | 超卖，但先确认不是逻辑变坏 |
| 0–15% | 贴下轨 | 支撑区，可对比股息率是否已到买点 |
| 15–40% | 中轨下方 | 偏弱 |
| 40–60% | 中轨附近 | 中性 |
| 60–85% | 中轨上方 | 偏强 |
| 85–100% | 贴上轨 | 压力区 |
| > 100% | 突破上轨 | 超买 |

带宽 `(上轨−下轨)/中轨 < 4%` 时统一标「窄幅横盘」，不给贴轨信号——横盘时价格会在窄幅里来回穿轨，假信号特别多。

页面上的「距下轨 +2.3%」是**带符号距离**：负数表示在轨道内、正数表示已经跑出轨道（例如「距下轨 −1.2%」＝已跌破下轨 1.2%）。

**必须前复权**：红利股每年除权价格会跳空，不复权会在除权日造出假的「跌破下轨」。

三轨一天只算一次（日频指标，盘中不变），而「现价到轨的距离」随行情实时变——所以看盘时位置在动、轨道不动，是正常的。

## 怎么用

手机上打开 **https://algatross.github.io/hongli-workbench/** → 浏览器菜单里选「添加到主屏幕」→ 以后像个 App 一样点开。

**日常不用维护**：股价、分红核对、布林、历史快照全是自动的。只有改代码时才需要推送。

详细部署与排错见 [部署说明.md](部署说明.md)。

## 数据从哪来

| 内容 | 来源 | 更新方式 |
| --- | --- | --- |
| 股价 / 涨跌 | 腾讯财经 `qt.gtimg.cn` | 打开页面时实时抓，超过 4 小时或跨日自动重抓 |
| 每股分红 | 东方财富 `RPT_SHAREBONUS_DET` | 页面会比对公告，有差异弹提示条告诉你 |
| 自选股代码查询 | 东方财富 `searchapi` | 输入名称时自动匹配，有多个候选会列出 |
| 布林通道 | 东方财富 `push2his` 日 K（前复权） | 优先读 `boll.json`（Actions 每日生成）；没有就浏览器现场算，当天算过就缓存 |
| 历史收盘价 | 本仓库 `历史收盘价.csv` | GitHub Actions 每工作日 16:10 自动抓取并提交 |
| 持仓 / 自选 / 汇率 | 浏览器 localStorage | 只存你这台设备，不上传、不同步 |

**页面本身是死代码，数据是活的。** 推到仓库的只是这个 HTML，股价和分红都是你手机打开时去接口现取的，不经过 GitHub。

`boll.json` 是预生成数据：110 只 × 三轨约 8KB，页面一个请求读完，省掉上百个 K 线请求。它不存在也不影响使用，页面会退回到现场计算。

## 口径说明

- 买点价 = 每股分红 ×（1 − 税率）÷ 目标股息率
- **税率（v1.9 起 A 股按持股期限分档）**：

| 类型 | 税率 | 说明 |
| --- | --- | --- |
| A 股·满 1 年 | **0%** | 持股 ≥365 天免征 |
| A 股·1 月~1 年 | **10%** | 减按 50% 计入，实际 10% |
| A 股·<1 月 | **20%** | 全额计税 |
| 港股通 H 股 | 20% | 大陆注册企业的 H 股 |
| 港股通非 H 股 | 28% | 港/海外注册（红筹） |
| 香港账户直接持有 | 10% | |

  A 股的档位取自**持仓里录的买入日期**；未录则按「满 1 年免征」估算并在卡片上标 `*`。
  实际是派息时全额发放、卖出时按持有期限补扣，所以页面算的是「按该期限一直持有」的税后口径。

- 股息率 = 每股分红 ×（1 − 税率）÷ 现价（港股按汇率折算人民币后再比）
- 分红取「最近一个**完整财年**（有年报的那个）各期已实施派息合计」，不是「除权日往前滚 12 个月」——
  后者会把中期分红重复计入，工行会虚高到 5.29%
- **财年归集**：6-30 / 9-30 归本财年，次年 3-31 / 4-30 归上一财年。
  按报告期年份累加会把下一年度中期算进来（或反过来只取到中期，低估一半）
- 行业水位用**中位数**，不用平均值（个别特别分红会把平均值拉飞）

## 自选区

日常关注的股票，与 110 只池子**完全独立**：不影响买点排名、不影响行业统计。

- 加：填 6 位代码直接加；填中文名点「查代码」自动匹配
- 池内标的加入时自动带出分红与税率；池外标的需自己填每股分红
- 排序：添加顺序 / 按股息率 / 按涨跌幅
- 可写备注（如「等 5.5% 加」）

初始清单 11 只写在源码 `DEFAULT_WATCH` 里，新设备首开自动出现。

## 股票池怎么来的

**先说清楚：这不是一个「股息率≥4.5%」的池子，而是精选池。**

110 只 = 97 只 A 股 + 13 只港股，覆盖 33 个细分板块。

**2026-11-02 扩容时新增标的的入选规则**：

FY2025 全市场扫描（3,449 只有分红的 A 股）→ 股息率 ≥4.5% → 连续分红 ≥3 年 → 市值 ≥200 亿 → 人工筛掉一次性分红陷阱（荣晟环保 17.79%、汇洁股份 15.30% 这类）。

**这套规则只对新加入的标的生效**。原有的老标的按「股息率 <3% 才剔除」保留，
所以池内目前有 **27 只低于 4.5%**（最低的神火股份 3.12%），
它们是历史留存，不是新规则筛出来的。

市值门槛是为了过滤「今年卖资产大比例分红、明年就没了」的标的，不是嫌小盘股不好。

> 想只看高息的：用「买点」页顶部按股息率排序，或自己用「自选」把关心的挑出来。
> 池子与自选是两套东西——池子是扫描结果，自选是你的关注。

## 免责

股息率是**过去**的分红除以**现在**的股价。分红会砍，股价会跌，除权还会把价格打下来。
这里只做算术，不构成任何投资建议。所有数据使用前请自行核对公告。
