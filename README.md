# 红利买点工作台

一个单文件的红利股买点看板。打开即用，行情实时抓，持仓/自选只存在你自己手机里。

- **买点**：按目标股息率（3%~9%）倒算「跌到多少才值得买」，标出当前价已经触到哪一档。每张卡片带一条**布林轨道尺**，一眼看出便宜还是贵
- **行业**：12 个一级行业、110 只标的，看各行业股息率中位数水位
- **矩阵**：全池按股息率 / 距下一档差距排出强弱；可切「布林 × 股息 交叉」看四象限
- **持仓**：算成本、算浮盈、算按现价加仓后的摊薄股息率
- **推演**：改股价 / 改分红，实时算股息率怎么变
- **数据**：数据源、最后一次成功刷新时间、版本号、导出导入

## 布林通道怎么看

采用 **20 日 ±2σ、前复权**，与通达信 / 同花顺默认口径一致（标准差用「总体」而不是「样本」，否则轨会偏宽，跟你看盘的软件对不上）。

| 位置（现价在上下轨之间） | 标签 | 含义 |
| --- | --- | --- |
| < 0% | 跌破下轨 | 超卖，但先确认不是逻辑变坏 |
| 0–15% | 贴下轨 | 支撑区，可对比股息率是否已到买点 |
| 15–40% | 中轨下方 | 偏弱 |
| 40–60% | 中轨附近 | 中性 |
| 60–85% | 中轨上方 | 偏强 |
| 85–100% | 贴上轨 | 压力区 |
| > 100% | 突破上轨 | 超买 |

带宽 `(上轨−下轨)/中轨 < 4%` 时统一标「窄幅横盘」，不给贴轨信号——横盘时价格会在窄幅里来回穿轨，假信号特别多。

页面上的「距下轨 +2.3%」是**带符号距离**：负数表示在轨道内、正数表示已经跑出轨道（例如「距下轨 −1.2%」＝已跌破下轨 1.2%）。

**必须前复权**：红利股每年除权价格会跳空，不复权会在除权日造出假的「跌破下轨」。

三轨一天只算一次（日频指标，盘中不变），而「现价到轨的距离」随行情实时变——所以看盘时位置在动、轨道不动，是正常的。

## 数据从哪来

| 内容 | 来源 | 更新方式 |
| --- | --- | --- |
| 股价 / 涨跌 | 腾讯财经 `qt.gtimg.cn` | 打开页面时实时抓，超过 4 小时或跨日自动重抓 |
| 每股分红 | 东方财富 `RPT_SHAREBONUS_DET` | 页面会比对公告，有差异弹提示条告诉你 |
| 布林通道 | 东方财富 `push2his` 日 K（前复权） | 优先读 `boll.json`（Actions 每日生成）；没有就浏览器现场算，当天算过就缓存 |
| 历史收盘价 | 本仓库 `历史收盘价.csv` | GitHub Actions 每交易日 16:10 自动抓取并提交 |
| 持仓 / 自选 / 汇率 | 浏览器 localStorage | 只存你这台设备，不上传、不同步 |

**页面本身是死代码，数据是活的。** 推到仓库的只是这个 HTML，股价和分红都是你手机打开时去接口现取的，不经过 GitHub。

`boll.json` 是唯一的「预生成数据」：110 只 × 三轨约 8KB，页面一个请求读完，省掉上百个 K 线请求。它不存在也不影响使用，页面会退回到现场计算。

## 口径说明

- 买点价 = 每股分红 ×（1 − 税率）÷ 目标股息率
- 税率：A 股 0%（持股超 1 年免税）、港股通 H 股 20%、港股通非 H 股 28%、香港账户 10%
- 股息率 = 每股分红 ×（1 − 税率）÷ 现价（港股按汇率折算人民币后再比）
- 分红取「最近一个完整财年各期已实施派息合计」，不是「除权日往前滚 12 个月」——
  后者会把中期分红重复计入，工行会虚高到 5.29%
- 行业水位用**中位数**，不用平均值（个别特别分红会把平均值拉飞）

## 股票池怎么来的

FY2025 全市场扫描（3,449 只有分红的 A 股）→ 股息率 ≥4.5% → 连续分红 ≥3 年 → 市值 ≥200 亿 → 人工筛掉一次性分红陷阱（荣晟环保 17.79%、汇洁股份 15.30% 这类）。

市值门槛是为了过滤「今年卖资产大比例分红、明年就没了」的标的，不是嫌小盘股不好。

## 免责

股息率是**过去**的分红除以**现在**的股价。分红会砍，股价会跌，除权还会把价格打下来。
这里只做算术，不构成任何投资建议。所有数据使用前请自行核对公告。
